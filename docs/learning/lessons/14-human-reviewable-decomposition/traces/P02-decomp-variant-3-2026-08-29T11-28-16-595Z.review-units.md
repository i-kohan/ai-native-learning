## Unit A

intent: Establish due-date capability: Task.dueAt, create/default/validation, and complete/reopen preserve dueAt.

acceptance:
- A task created without dueAt has dueAt equal to null.
- A task created with dueAt null succeeds and returns null.
- A valid non-empty parseable dueAt string succeeds and is returned byte-for-byte as supplied.
- Invalid create dueAt values produce HTTP 400 and do not create a task.
- Completing and reopening a dated task preserve its exact dueAt; reopening a previously completed overdue task makes it appear in overdue results again.
